# FIFA World Cup 2026 - 評価手法

## プロジェクト概要

このプロジェクトは、FIFA World Cup 2026（48チーム、12グループ）の全試合を予測・分析するためのデータ基盤です。
グループステージ72試合の予測から、ノックアウトステージを経て優勝チームを予測します。

## ディレクトリ構成

```
data/       - 生データ（チーム・選手・グループ・試合スケジュール）
analysis/   - 各チーム分析レポート (Markdown)
predictions/- グループステージ・ノックアウトの予測JSON
scripts/    - 順位計算・シミュレーション・レポート生成スクリプト
```

## チーム評価指標

### 1. 選手レーティング
- スターティング11の平均レーティング（FIFA / Sofascore 等を参照）
- ベンチ深度（控え選手の質）
- GK・DF・MF・FWの各ラインの強度

### 2. 戦術・組織力
- フォーメーションの柔軟性
- ハイプレス耐性とポゼッション能力
- セットプレー（CK・FK）の得点力と守備力

### 3. 直近成績
- 直近12試合の勝率・得失点
- 予選成績（グループ内順位・得失点差）
- 主要大会（コンフェデ杯・欧州選手権など）での実績

### 4. グループ内相性
- 過去の直接対決（W杯・親善試合）
- 気候・会場への適応力（北米開催）
- 同グループの他チームとの実力差

## 試合予測の判断基準

| 要素 | 重み |
|------|------|
| 選手レーティング差 | 35% |
| 直近12試合の成績 | 25% |
| 戦術的相性 | 20% |
| 過去の直接対決 | 10% |
| ホームアドバンテージ・会場 | 10% |

### スコア予測の方針
- 実力差が大きい場合：1-0 〜 3-0 程度
- 互角の場合：1-1 引き分け or 1-0 の僅差
- ノックアウトは延長・PK戦も考慮

## データソース

- **FIFA公式ランキング**: https://www.fifa.com/fifa-world-ranking/
- **Transfermarkt**: チーム市場価値・選手情報
- **Sofascore / WhoScored**: 試合統計・選手レーティング
- **ESPN / BBC Sport**: 最新ニュース・コンディション情報
- **FBref**: 詳細な試合統計（xG、パス精度など）

## 更新フロー

1. `data/matches/schedule.json` に予測スコアを入力
2. `scripts/calc_standings.py` でグループ順位を確認
3. `scripts/third_place.py` で3位通過チームを確定
4. `predictions/knockout/round_of_32.json` を作成
5. `scripts/simulate_knockout.py round_of_32` で次ラウンドを生成
6. 以降のラウンドを繰り返し
7. `scripts/report.py --md` で最終レポートを生成
